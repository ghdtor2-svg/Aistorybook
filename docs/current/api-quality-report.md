# 실제 플랫폼 API 이미지 품질 점검

2026-11-07. 실제 플랫폼의 `/api/storybook/illustrations` 제작 경로로 입체 인형과 수채화에서 각각 표지 1장·이어지는 펼침면 1장을 생성했다. 총 4건이 성공했다. 별도 편집으로 그림을 보정하지 않았다.

- 모델: gpt-image-2, high 품질, 표지 1024×1536·펼침면 3072×1024, JPEG 품질 92.
- 입력: 실제 고객 정보가 없는 ‘하루와 할머니의 별빛 정원’ 내부 검증 원고.
- 표지는 선택 화풍 예시를 참고했고, 펼침면은 API가 만든 표지를 참고했다. 실제 제품과 같은 동작이다.
- 확인: 두 화풍 모두 얼굴·손·의상의 표현, 배경 질감, 참조 표지와 다음 그림의 인물·고유색 유지, 전체 비율과 중앙 여백을 시각적으로 점검했다. 제시한 예시와 비교할 만한 고품질 결과를 확인했다.
- 생성 시간: 입체 인형 표지 약 82초·펼침면 47초, 수채화 표지 88초·펼침면 52초. 네 그림의 순수 요청 시간 합계는 약 270초다. 한 작품 전체 소요 시간으로 일반화하지 않는다.

## 결과를 해석할 범위

이 정도의 그림을 실제 플랫폼 API로 만들 수 있다는 증거다. 그러나 모든 요청이 같은 만족도를 보장한다는 뜻은 아니다. 열 가지 중 나머지 여덟 화풍, 한 편의 그림 18장 전체의 장면 차별성과 캐릭터 일관성, 전체 완주·실패 복구·실측 비용은 아직 검증하지 않았다. 실제 청구액은 이 기록에서 측정하지 않았다.

판매 화면에서는 열 가지 ‘화풍 참고 이미지’와 여기서 확인한 ‘실제 제작 예시’를 구분한다. 수동 편집한 사계의 탑 전체를 자동 생성 결과물처럼 소개하지 않는다.

## 파일

`results.json`에는 키·코드 없이 모델·품질·성공 상태·요청 시간이 있다. 원본 결과는 `soft-clay-cover.jpg`, `soft-clay-panorama.jpg`, `watercolor-cover.jpg`, `watercolor-panorama.jpg`다. 웹용 WebP는 플랫폼의 `public/storybook/quality-proof`에 있다.

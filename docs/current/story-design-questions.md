# 동화 질문 고도화 적용

기존 핵심 질문 5개와 질문당 최대 후속 질문 2개의 흐름은 보존했다. 각 질문의 도움말은 사건·행동·감정·캐릭터의 고유색을 구체적으로 떠올릴 수 있도록 보강했다.

핵심 답변을 확인하는 화면에 선택형 이야기 설계 질문 9개를 추가했다.

1. 독자의 나이·읽기 수준·분위기·이야기 목소리
2. 캐릭터의 외형·고유색·소품·관계
3. 장소·시간·세계의 규칙과 제한
4. 구체적인 목표·장애물·첫 실패
5. 주인공의 재도전과 절정의 선택
6. 시작과 결말의 감정·행동 변화
7. 초반 단서의 중간 역할과 결말 회수
8. 발견·실패·절정·마무리의 서로 다른 시각적 장면
9. 보존할 사실·허용한 각색·피할 표현

학교·새 친구, 이별·이사 등 기존 답변에 포함된 명시적 단어에 따라 목표 질문의 표현을 조정한다. 의미 이해 AI가 동작한다고 주장하지 않으며 질문·저장·건너뛰기에는 외부 AI 호출이 없다. 선택 질문을 건너뛰어도 생성 전 내용 확인을 할 수 있다. 예시를 자동으로 답변에 넣지 않는다.

질문 답변은 브라우저 저장과 작성본 JSON/TXT 내보내기·가져오기로 보존한다. 설계 답변을 수정하면 최종 확인을 다시 받는다. 기존 질문 작성본의 질문 ID, 저장 버전, 기존 책장과 고객 주문은 보존했다.

설계 답변은 storyBrief를 통해 실제 생성 입력에 전달된다. 주인공의 선택이 사건을 바꾸는 인과·감정의 행동 표현·단서 회수·등장인물과 소품 연속성·본문 4500~6500자·5장·32쪽과 그림18장 편집 기준을 함께 전달한다. 정기 구독 생성 실행기도 같은 제작 기준을 재사용하도록 반영했다.

검증: TypeScript 검사, 기존 질문 엔진 회귀, 작성본 내보내기·가져오기 회귀, 새 설계 질문의 저장·복원·분기·입력 검증·생성 입력 전달 검사 통과. 별도 localhost 가상 작성본으로 질문9개 표시, 답변 저장, 새로고침 복원, 수정 후 재확인, 가로 넘침 없음 확인. 기존 127.0.0.1 브라우저 작성본은 수정하지 않았다.

이번 변경은 ‘사계의 탑’을 목표로 이야기 재료와 제작 지시를 고도화한 것이다. 이 변경으로 새 동화를 실제 생성해 이전 결과와 품질을 비교하는 실험은 하지 않았다. 질문만으로 삽화 품질이나 최종 완성도를 보장하지 않는다. 로컬 적용과 공개 배포는 별개다.

# 주문 백오피스 구축 기록

## 제공 기능

- 로컬 전용 `/office/orders`, 기존 사무실 관리자 비밀번호로 로그인·로그아웃.
- 주문 현황, 최근 500개 주문 목록·검색, 주문 상세·입금 확인 여부·작품 제목·그림 완료 수·포함 수정 사용 여부.
- 입금 확인 후 5,000원 제작 키 발급. 별칭·운영 메모 보관과 수정.
- 전체 키는 목록에서 숨기고 관리자 요청 시에만 확인·복사.
- 같은 주문에서 키 재발급, 이전 키 중지, 기존 작품·그림·수정 횟수 보존.
- 제작 중인 주문은 키 재발급·중지 차단. 실제 생성 직전에도 키가 바뀌거나 중지되지 않았는지 재검사.
- 최근 100개 관리 작업 이력.

## 검증

최종 빌드, 기존 32쪽·18장·브라우저 독립 제작·복구·수정 제한 모의 검사 통과. 백오피스 로그인·권한 검사, 키 발급·검색·메모, 키 재발급·중지와 기존 결과 보존, 진행 중 변경 차단, 로그아웃, 1280px·390px 화면 검사를 통과했다. 새 유료 API 호출은 하지 않았다.

## 공개와 데이터

백오피스는 로컬 전용이다. 공개용 페이지 확장자 구분을 유지하고 관리자 페이지와 API를 공개 빌드에서 제외한다. 실제 발급 키·주문·고객 사연·관리자 비밀번호는 GitHub 업로드 대상에서 제외한다. 보관 데이터 전체 삭제, 관리자 다중 계정과 클라우드 주문 저장은 후속 작업이다.

대표가 정확한 공개 저장소와 업로드 파일 범위를 명시적으로 승인했다. 기존 거절 상태는 이 범위에 대해 해소되었으며, 코드·가짜 테스트 자료·공개 샘플·문서만 GitHub에 저장한다.

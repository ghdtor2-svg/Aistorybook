# 제작 안정성 우선 수정

## 완료

- 사용자 요청에 따라 일회성 예약 `17-30`을 실제 삭제했다. 도구 결과는 deleted이며, 이전의 삭제 승인 대기 상태는 해소됐다.
- 삽화 18장을 브라우저가 한 장씩 호출하던 방식을 로컬 백그라운드 작업자로 변경했다. 시작 요청을 받으면 진행 상태와 원고를 주문 파일에 저장하고, 작업자가 순서대로 처리한다.
- 탭을 닫아도 로컬 컴퓨터와 제작 서버가 켜져 있으면 제작을 이어 간다. 다시 접속해 코드를 입력하면 진행 상태와 결과를 가져온다.
- 작업자는 이미 완료된 그림을 건너뛴다. 작업 중복을 막는 잠금, 진행 중 그림 표시, 서버별 작업 주소 구분을 적용한다.
- 유료 요청의 완료 여부가 불확실하면 자동 재시도하지 않고 멈춘다. 재개 전에는 사용량이 다시 발생할 수 있음을 확인한다. 장애 후 상태를 모르는 그림을 조용히 다시 제작하지 않는다.
- 제작·수정 중에는 해당 책의 직접 글 편집과 책장 삭제를 막아 진행 원고와 결과가 어긋나는 일을 줄였다.

## 확인한 검사

- 최종 Next 빌드 통과.
- 가짜 API를 사용해 실제 브라우저 탭을 닫은 동안 그림 18장 완성, 새 탭에서 코드 입력 후 복구를 확인했다.
- 32쪽 분배, 원본 비율·모바일 표시·그림 확대, 비공개 그림 접근, 중복 글 생성 방지, 그림 수정 실패 후 재시도와 1회 제한을 다시 확인했다.
- 중간 유료 요청이 완료됐는지 모르는 상황을 재현해 자동 제작 중단과 추가 확인 없는 재시작 거절을 확인했다.
- 이 수정 검증에서 실제 유료 API 호출은 하지 않았다.

## 범위와 남은 일

현재는 로컬 전용이다. 컴퓨터와 제작 서버를 끄면 계속 제작된다고 보장하지 않는다. 다시 켰을 때 저장된 완료분은 유지하며, 진행 중이던 요청의 상태가 불확실하면 확인 후 재개한다. 공개 서비스용 작업 서버·영속 저장소·운영 점검은 별도 작업이다.

GitHub 공개 업로드는 여전히 `ghdtor2-svg/Aistorybook`에 대한 명시적 대상 승인 대기다. 이 요청에서 예약 삭제는 승인받았지만 공개 저장소 업로드까지 승인받은 것으로 확대하지 않았다. 사이트 배포 완료를 주장하지 않는다.

# 화풍 예시와 메인 샘플 개선

## 적용 내용

- 열 가지 화풍을 서로 다른 장면으로 새로 제작해 교체했다. 수채화의 번짐, 과슈의 불투명한 붓질, 애니메이션의 선과 풍경, 코믹스의 잉크선과 역동성, 입체 인형의 조형감, 색연필 선, 파스텔 분말, 수묵의 여백, 유화 붓질, 양모 섬유가 잘 드러나는 예시다.
- 선택 화면에 화풍별 특징 설명, 확대 보기, 현재 선택 안내를 추가했다. 확대만으로 선택을 바꾸지 않는다. 원본 비율을 유지한다.
- 별도 화풍 갤러리와 비교 이미지도 새 예시로 교체했다. 브라우저에 예전 그림이 남지 않게 URL 버전을 변경했다.
- 새 예시는 실제 플랫폼의 최초 표지 제작에도 화풍 참조로 사용된다. 고객 작품의 인물·장소는 고객 이야기로 만들며 예시 속 인물을 복사하지 않도록 한 기존 지시는 유지한다.
- 메인의 가상 책 모형을 「사계의 탑」 실제 표지 그림으로 교체했다. 샘플 두 펼침면, 읽을 수 있는 본문 발췌, 장면 선택, 전체 PDF와 화풍 선택 이동을 추가했다.
- ‘샘플 작품’ 및 별도 편집·검수한 기준 작품이라는 안내를 표시한다. 자동 생성 품질 보증과 구분한다. 소개의 오래된 ‘장별로 읽기’ 문구도 연속된 이야기 읽기에 맞게 수정했다.

## 그림 제작 방식과 파일

내장 이미지 생성 도구로 열 장을 각각 제작했다. 별도 유료 API 키를 사용한 호출은 하지 않았다. 원본 PNG와 최종 프롬프트·원본 경로 기록은 `outputs/style-examples-v2`에 보관했다. `prompts-and-sources.json`에 최종 열 개 프롬프트가 있다. 비교 이미지는 같은 폴더의 `overview.jpg`다.

웹용 파일은 `public/storybook/styles`의 열 개 WebP, 갤러리와 비교 이미지다. 메인 샘플은 `public/storybook/sample`의 표지와 두 펼침면이다. 기존 검수 샘플로부터 웹용 크기만 변환했다.

## 검증

프로덕션 빌드 통과. 가짜 API 서버를 사용하는 브라우저 검사에서 메인 2개 장면 전환, 전체 샘플 PDF 응답, PC 1280px·모바일 390px 화면 넘침 방지, 화풍 확대 후 선택 유지·Escape 닫기, 기존 코드 발급·32쪽·그림 18장·수정 제한 흐름을 확인했다. PC·모바일 캡처도 시각적으로 검토했다.

실제 유료 API로 새 그림 18장을 만드는 검증이나 공개 배포는 하지 않았다. 판매가격·결제 방식은 변경하지 않았다.

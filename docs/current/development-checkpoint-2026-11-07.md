# 동화 플랫폼 후속 개선 기록

2026-11-07. 유료 API 호출 없이 적용할 작은 개선부터 진행했다.

## 이번 완료 범위

- 신규 공유 펼침면의 그림을 글 위·아래로 번갈아 배치. 이미지 비율 보존.
- AI 요청에서 요약 항목 400자·각색 500자 잘라내기 제거. 확인된 요약 전체 전달. 클라이언트·서버 공통 100,000자 상한과 JSON 요청 길이 제한. 상한 초과 시 생성 기록을 만들기 전에 안내.
- 그림 크게 보기, 전체 보기/더 크게 보기, 스크롤, 닫기·Escape와 포커스 복귀.
- 그림 수정 전 선택한 원본 미리보기, 작품당 1장 1회 및 공유 펼침면 양쪽 변경 안내. 수정본 표시도 실제 장면 이름 사용.
- 그림 로딩 상태·실패 안내와 기존 파일 다시 불러오기. 다시 불러오기는 그림 생성 API를 호출하지 않음.
- 글 수정 화면에 페이지 재배치와 기존 그림이 자동 변경되지 않는다는 안내.

## 검증

- Next 프로덕션 빌드, 기존 질문 엔진 검사 통과.
- 긴 한글·이모지 요약과 각색 끝부분 보존, 길이 초과 거절 확인.
- 별도 로컬 서버와 가짜 API로 4,000자 초과 입력의 끝부분 전달 확인.
- PC 1280px·모바일 390px 그림 원본 비율, 확대·1600px 상세 보기, Escape 닫기·포커스 복귀 확인.
- 코드 발급, 중복 생성 방지, 32쪽·그림 18장, 비공개 그림 접근, 실패 후 수정 재시도·1회 제한 흐름 통과.
- 저장된 그림 파일 요청을 한 번 실패시킨 뒤 다시 불러오기 복구 확인. 생성 요청을 추가하지 않음.
- 실제 이미지 품질·API 청구액 검증은 하지 않음.

3. 실제 API 1편 품질·시간·원가 측정은 유료 사용 범위를 확인한 뒤 진행.

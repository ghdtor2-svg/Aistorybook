# 32쪽 기본 상품과 가격 제안

2026년 11월 7일 대표 지시에 따라 모든 신규 작품의 제작·원가 산정 기준을 ‘사계의 탑’ 수준의 32쪽과 그림 총 18장으로 통일했다.

## 기본 구성

- 표지 포함 32쪽, 본문 약 5,000자
- 표지 1장과 본문 삽화 17장, 합계 18장
- 같은 장면은 두 페이지가 하나의 가로형 그림을 공유하고, 장면 전환부는 서로 다른 그림을 배치
- 열 가지 화풍 중 고객이 선택한 화풍을 작품 전체에 유지
- 캐릭터 외형과 고유색 유지, 큰 글자와 읽기 쉬운 문단, 인물 잘림과 중앙 접힘 확인

## 예상 원가

API 예산은 한 편당 약 3,900~4,500원이다. 글 생성, 참조 그림 입력, 그림 18장, 가벼운 내용 수정과 그림 수정 1회 여유를 고려한 추정치다. 1달러를 1,500원으로 가정했으며 실제 환율이 아니다. 서버·보관 비용, 결제 수수료, 고객 응대, 세금은 별도다.

공식 계산기의 보수적 표시액으로 표지와 일반 삽화 4장에 각각 $0.16464, 가로형 펼침면 14장에 각각 $0.11856를 적용하면 그림 출력 소계는 $2.3184다. 여기에 참조 입력 예산 $0.27, 글 생성 예산 $0.02를 더하면 약 3,913원이다. 가로형 그림 수정 1회는 입력 예산을 합쳐 약 200원을 추가하는 가정이다. 실제 출력·입력 사용량과 수정 범위에 따라 달라진다. [공식 이미지 생성 계산기](https://developers.openai.com/api/docs/guides/image-generation)

공식 가격표의 GPT Image 2 출력 요금과 계산기의 표시 요금에 차이가 있어 높은 계산기 표시액을 예산에 적용했다. 실제 계정의 사용량·청구 내역으로 확인한 뒤 보정해야 한다. [공식 API 가격표](https://developers.openai.com/api/docs/pricing)

## 권장 판매가격안

| 항목 | 권장 고객 가격 | 범위 |
| --- | ---: | --- |
| 최초 생성 | 9,900원 | 32쪽, 그림 18장, 화풍 선택, 아래 기본 수정 포함 |
| 이미지 제작 전 AI 내용 조정 | 1회 포함 | 처음 제공한 이야기와 인물 설정 안에서 조정 |
| 포함된 그림 수정 | 1장 1회 포함 | 같은 인물과 장면을 유지한 표정·색감·일부 소품 조정 |
| 고객이 직접 문구 고치기 | 무료 | 새 그림이나 AI 재생성을 요구하지 않는 직접 편집 |
| 포함 횟수 이후 AI 글 수정 | 요청당 1,000원 | 이름·말투·일부 문장 조정, 그림 재생성은 별도 |
| 포함 횟수 이후 그림 수정 | 장당 1,000원 | 그림 한 장의 부분 수정 |
| AI 글과 관련 그림 1장 함께 수정 | 요청당 2,000원 | 추가 글 조정과 그림 한 장 재생성 |
| 줄거리·주인공 외형·화풍의 전면 변경 | 9,900원 | 전체 작품 재제작 |
| 시스템 장애·명확한 제작 오류 보정 | 무료 | 합의한 요청의 누락, 파일 손상 등 제작 측 오류 |

그림을 만든 뒤 글을 바꿔 그림도 달라져야 하면, 바뀌는 그림 수를 먼저 확인해 총 수정액을 안내하는 방식을 제안한다. 작은 글 수정이 자동으로 전체 그림 재생성으로 이어지지 않도록 한다.

## 가격 제안의 근거

9,900원에서 API 예산 3,900~4,500원을 빼면 5,400~6,000원이 남는다. 여기서 결제·보관·응대·세금·추가 실패 대응 비용을 충당한다. 기존 5,000원으로 같은 구성을 판매하면 API 비용을 뺀 여유가 500~1,100원이라 운영 비용을 감당할 여유가 작다.

이 제안은 원가와 수정 대응 부담을 바탕으로 한 초기 가격안이다. 고객의 지불 의사는 시장 검증으로 확인해야 한다.

## 실제 적용 상태

신규 생성의 32쪽·그림 18장 기준은 코드와 프로젝트 지침에 반영한다. 기존 작품의 생성·수정 진행 기록은 기존 구성으로 복구하도록 호환성을 유지한다.

9,900원과 추가 수정료는 대표 검토용 제안이다. 판매가격 변경이 확정되기 전 실제 코드 발급 금액과 공개 판매가는 현재 승인된 5,000원을 적용한다. 유료 추가 수정 결제 기능도 가격 확정 이후 별도 구현이 필요하다.

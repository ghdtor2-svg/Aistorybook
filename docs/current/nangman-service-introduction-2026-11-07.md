# 낭만한줄 소개 · 외부 AI 검토용

## 서비스 개념

낭만한줄은 아이의 정보와 가족의 사연을 바탕으로 우리 가족만의 디지털 동화를 만드는 AI 맞춤형 동화 서비스입니다. 부모가 직접 긴 이야기를 쓰는 대신, 질문에 답하며 소재를 정리하고 AI가 이를 하나의 이야기로 풀어냅니다.

고객은 이야기 요약과 허용할 각색을 확인하고 수채화, 입체 인형, 색연필 등 열 가지 화풍 중 원하는 표현을 고릅니다. 제작의 기본 기준은 약 5,000자의 글, 표지 포함 32쪽, 표지와 본문 삽화 총 18장입니다. 같은 장면은 두 페이지에 걸쳐 하나의 그림으로 이어지게 하고, 캐릭터의 모습과 고유색이 유지되는 동화책을 지향합니다.

첫 사업 목표는 많은 기능을 제공하는 것보다, 부모가 자신의 사연이 담긴 이야기에 가치를 느끼고 비용을 지불할 의향이 있는지 확인하는 것입니다. 실물 책 제작·판매는 현재 범위에 포함하지 않습니다.

## 현재 이용 방식과 개발 상태

현재 승인된 동화 생성 가격은 1편 5,000원입니다. 운영자가 계좌이체 입금을 확인한 뒤 제작 코드를 발급하는 방식을 구현했습니다. 고객 회원가입은 요구하지 않으며 토스 결제는 비공개 상태입니다.

질문 작성과 요약 확인, 화풍 선택, 코드 기반 AI 글·그림 생성, 웹 읽기, 직접 글 수정, 작품당 그림 1장 수정 1회, 브라우저 책장과 백업 기능이 로컬에 구현되어 있습니다. 글 생성 후 삽화 제작은 별도로 시작하며, 그림은 한 장씩 순서대로 만들어집니다.

다만 일반 고객에게 공개 운영할 준비가 끝난 상태는 아닙니다. 현재 생성 기능은 로컬에서만 작동하도록 제한되어 있습니다. 「사계의 탑」 샘플은 별도로 편집·검수한 기준 작품이며, 플랫폼의 자동 생성 결과가 항상 그 완성도로 나온다는 검증은 남아 있습니다. 고객별 작품의 PDF 자동 제공 기능도 아직 연결되지 않았습니다.

추가 점검에서 실제 플랫폼 API로 입체 인형과 수채화의 표지·펼침면 총 4장을 생성해 고품질 결과를 확인했습니다. 두 화풍에서 실제 구현 가능성을 확인한 것이며, 나머지 화풍과 한 편의 그림 18장 전체를 보증하는 결과는 아닙니다. 화면에서도 화풍 참고 이미지와 실제 제작 결과를 구분합니다.

## 앞으로 개선하려는 방향

우선 실제 API로 32쪽·그림 18장 작품을 끝까지 제작해 품질, 소요 시간과 비용을 확인하려 합니다. 이후 화면을 닫아도 제작이 이어지는 구조, 그림과 글이 자연스럽게 어우러지는 편집, 캐릭터 일관성, 모바일 읽기, 수정 범위 안내와 고객 작품 PDF 제작을 개선할 계획입니다.

기존 API 비용 추정은 한 편 약 3,900~4,500원이며 실측 전 예산입니다. 서버·수수료·세금·고객 응대는 포함하지 않습니다. 이 구성의 권장 판매가로 9,900원이 제안되었지만 아직 확정하거나 적용하지 않았습니다. 추가 AI 글 수정과 유료 그림 수정도 제안 단계입니다.

3. 샘플 수준의 자동 생성 품질을 확보하기 위해 무엇을 먼저 검증해야 하는가?
4. 현재 원가 가정에서 5,000원과 제안 가격 9,900원은 각각 어떤 조건에서 지속 가능한가?
5. 회원가입 없는 코드 방식과 페이지·그림 수정 경험은 어떻게 개선해야 하는가?

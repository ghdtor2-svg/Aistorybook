# 구매 안내 위치·가격·복사 버튼 수정

대표의 2026-11-10 후속 요청으로 판매가를 9,900원으로 확정했다. 상품 공통 상수와 사무실 생성 지침, 현재 AGENTS 기준을 함께 변경했다. 과거 주문의 가격 기록과 이전 보고서는 소급해서 고치지 않는다. 수정 포함 횟수나 추가 수정 요금은 이번 가격 변경으로 승인된 것으로 취급하지 않는다.

홈의 결제 안내를 샘플과 이용 안내 다음인 맨 아래로 옮겼다. 동화 화면에서도 제작 코드 입력란 위에서 제거하고 책장 등 모든 내용 다음으로 옮겼다. 상단 구매 안내 바로가기는 유지했다.

동화 화면의 `.workshop button` 배경색 규칙이 계좌번호 복사 버튼의 단일 클래스 규칙보다 우선해, 보라색 글자가 보라색 배경에 표시됐다. 구매 안내 내 버튼에 한정한 더 구체적인 선택자로 배경과 흰색 글자를 함께 설정했다. 복사 실패 시 안내의 ‘아래 계좌번호’도 실제 위치에 맞게 ‘표시된 계좌번호’로 바꿨다.

타입 검사, 모의 API만 사용하는 cloud 회귀 검사, production 빌드를 통과했다. Chromium에서 홈·동화 두 페이지를 390px·1440px로 확인해 구매 안내가 main의 마지막 요소임을 확인했다. 9,900원 표시, 복사 버튼의 흰색 글자와 보라색 배경, 계좌번호 복사 성공, 안내 바로가기, 가로 넘침과 브라우저 오류 없음을 확인했다. 실제 입금이나 유료 AI 호출은 하지 않았다.

# 구매 문의·입금 안내 — 2026-11-10

대표가 고객 문의 채널을 인스타그램 `nangman_hanjul`의 DM으로 정하고 공개 입금 계좌를 제공했다. 공개용 정보는 `src/lib/storybook/purchase-info.ts` 한 곳에서 관리한다. 관리자 인증값과 API 키는 포함하지 않는다.

- 홈 첫 화면의 ‘구매 문의 · 입금 안내’ 버튼을 전용 안내 영역에 연결했다. 샘플보다 앞에 배치해 구매 의사가 있는 방문자가 연락 방법을 찾을 수 있다.
- 동화 화면 상단에도 안내 바로가기를 추가하고, 제작 코드 입력란 직전에 같은 연락·계좌 안내를 제공한다.
- 안내는 DM 문의 → 제작 가능 여부와 안내 확인 후 계좌이체 → 같은 DM으로 입금 확인 요청 → 담당자가 제작 코드 안내 순서다. 인스타그램 프로필에서 메시지를 보내며 로그인 필요 가능성을 알린다. 외부 링크는 새 창으로 열고 이를 표시한다.
- 은행·계좌번호·예금주, 계좌번호 복사와 성공·실패 안내를 제공한다. 자동 결제나 자동 입금 확인·즉시 코드 발급을 구현했다고 안내하지 않는다. 동화 생성 연결이 준비되지 않으면 먼저 DM 확인을 요청하며 기존 생성 제한을 유지한다.
- 기존 승인 가격 5,000원과 디지털 동화 상품 범위를 유지했다. 문의·입금 안내 화면을 추가한 것이며 실주문 발급·유료 AI 제작 완료 검증은 별도다.

검증: 타입 검사와 Netlify production 조건의 빌드 통과. Chromium에서 모바일 390px와 데스크톱 1440px의 가로 넘침 없음, 홈·동화 화면의 안내 이동, 인스타그램 링크 목적지, 계좌번호 복사·알림, 브라우저 오류 없음, POST 및 유료 API 호출 없음 확인. 인스타그램 메시지 전송과 실제 이체는 하지 않았다.

# 문장 경계 페이지 나눔 보완

대표 요청: 줄바꿈은 어절 단위, 페이지 이동은 문장이 끝난 뒤에만 한다.

원인: 기존 book-layout.ts는 긴 문장을 160자 부근에서 나누고, 31쪽을 채우기 위해 짧은 원고의 문장을 다시 쪼갰다. 마지막 본문도 어절 경계에서 반으로 잘랐다. 대화에서 만든 사계의 탑 샘플의 수동 편집도 글자 수 중간의 공백을 기준으로 나눴다.

변경: planStoryPages가 Intl.Segmenter의 한국어 문장 경계만 사용해 32쪽에 배분한다. 문장·문단·장 순서와 글을 보존한다. 빈 줄 앞의 문장이 미완성이면 다음 문단과 같은 쪽에 묶는다. 문장 수가 쪽수보다 적은 비정상적으로 짧은 원고는 빈 쪽을 허용하며, 쪽수를 채우려고 문장을 자르지 않는다. 정상 상품은 기존 약 2,500자 원고 기준이다. 화면은 overflow-wrap:normal과 word-break:keep-all을 사용한다. PDF는 강조 경계가 어절 중간에 있어도 같은 줄에 두며, 긴 어절을 음절로 쪼개지 않는다. 한 쪽의 글이 최소 글자 크기로도 들어가지 않으면 오류를 표시하고 PDF 출력을 중단한다.

사계의 탑은 새 AI 호출 없이 같은 18장 그림을 사용해 다시 편집했다. 기존 PDF 페이지 사이에 생긴 인위적 문단 구분을 제거하고, 각 장면 안의 좌우 페이지 분할에 같은 문장 배분 함수를 사용했다. 정규화한 전체 원고를 대상으로 모든 본문 페이지 시작·끝이 문장 경계인지 대조하고, 공백을 제외한 원문 보존도 확인했다. PDF는 표지·16펼침면·끝의 18쪽을 유지한다. 샘플 PDF 두 파일과 미리보기 두 장·캐시 버전을 갱신했다.

검증: test:layout(짧은/긴/빈 원고, 마지막 쪽, 대사, 원문 보존, 예시 문장, 어절 및 강조 경계), test:publication, test:scene-prompt, test:pdf, test:emphasis, typecheck 통과. scene-prompt 검사는 반복 문장의 오탐을 피하도록 fixture 문장을 구분하고, 의도적으로 허용한 직전 장면 대조문을 제외한 실제 지시 영역에서 혼입 여부를 검사한다. 새 PDF의 첫·마지막 본문 펼침면을 실제 렌더링해 확인했다.

이미 그림이 완성된 기존 작품을 새 페이지 배분으로 다시 열면 글과 그림의 연결 위치가 바뀔 수 있다. 이번 사계의 탑은 기존 장면 구분을 유지하며 각 장면 내부만 다시 나눠 이 문제를 피했다. 일반 기존 작품의 저장된 레이아웃 마이그레이션은 이번 변경 범위에 포함하지 않았다. 공개 사이트 배포는 하지 않았다.

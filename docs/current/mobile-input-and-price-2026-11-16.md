# 정가 대비 오픈 특가 표시와 모바일 질문 입력 개선

대표 지시: 정가 9,900원 대비 오픈 특가 5,900원이 두드러지게 보이게 하고, 배포 전에 모바일 질문 화면에서 답변 입력 중 반영 방식과 예시를 쉽게 볼 수 있도록 개선한다.

가격: 구매 안내와 동화 만들기에 같은 StoryPrice를 쓴다. 정가 9,900원은 취소선으로, 오픈 특가는 배지와 큰 5,900원으로 표시하고 정가 대비 4,000원 할인을 함께 보여준다. 실제 판매가·신규 주문 금액·SEO Offer는 5900을 유지한다. 할인 종료일은 추가하지 않는다.

모바일: 핵심/후속 질문의 반영 설명을 선택지 위에서 입력칸 바로 앞으로 옮겼다. 700px 이하에서는 예시를 먼저 보여주고 상세 설명을 펼칠 수 있다. 포커스와 visualViewport 크기 변경 시 안내와 입력칸이 함께 보이도록 위치를 맞춘다. 안내의 펼침/접기는 입력 포커스를 유지하고, 본문은 16px로 표시해 자동 확대를 피한다. 안내 스크롤과 짧은 입력창으로 키보드 위 공간을 확보하며, 상세 설명은 다시 접을 수 있다. 선택 질문 9개의 직접 입력에도 같은 모바일 안내를 추가했다. 데스크톱에서는 핵심 안내를 전체 표시하며 선택 질문의 기존 안내를 유지한다.

확인: 수정 전 375×400 화면에서 안내 영역이 화면 위(-416~-214px)로 밀려나 있었다. 수정 후 같은 조건에서 안내와 입력칸이 함께 보였다. Chromium에서 320·375·430px, 키보드 표시 공간을 가정한 높이 360~400px로 포커스·예시·펼침/접기·입력 유지·새로고침 복원·후속 질문 교체·선택 질문 입력을 검사했다. 정가/특가/할인액 표시, 특가 글자 크기가 정가의 두 배보다 큼, 모바일 가로 넘침 없음을 검사했다. 물리적 휴대폰의 실제 OS 키보드를 사용한 검증은 아니다.

배포 전 결과: npm run build, 운영용 서버의 관련 Playwright 11개 테스트, SEO 검사, 수정한 브라우저 테스트 3개 파일의 엄격 타입 검사를 통과했다. 기존 질문 선택 테스트는 비동기 자동 저장이 끝나기 전에 localStorage를 확인하던 부분을 expect.poll로 보완했다. 전체 test:browser 타입 검사는 기존 book-export·history-guard·question-import·story-tabs 등 미수정 파일의 타입 오류로 실패했으며, 이번 수정 파일의 타입 오류는 아니다. 실제 결제·유료 AI 생성은 실행하지 않았다.

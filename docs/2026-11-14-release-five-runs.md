# 배포 전 로컬 5회 검증

대표 지시: 첨부 PDF 파일은 수정하지 않는다. 외부 AI API 호출 없이 로컬에서 약 5회 검증하고 이상이 없으면 배포한다.

검증 대상 애플리케이션 리비전: ce43d4bd272bf5004e6ab6a9684cf3ff6e6647e1.
배포 확인 표식: public/release-info.json의 2026-11-14-checkout-publication-v1.

## 결과

| 성공 완료 회차 | 브라우저 시험 | PDF·한글·검수 게이트·장면 프롬프트 | 클라우드 모의 시험 |
| --- | --- | --- | --- |
| 1 (초기 2회차) | 36개 통과 | 통과 | 통과 |
| 2 (초기 3회차) | 36개 통과 | 통과 | 통과 |
| 3 (초기 4회차) | 36개 통과 | 통과 | 통과 |
| 4 (초기 5회차) | 36개 통과 | 통과 | 통과 |
| 5 (재실행) | 36개 통과 | 통과 | 통과 |

브라우저 전체 묶음을 정상 완료한 5회의 합계는 180개다. PDF 내려받기, 렜 글꼴 처리와 글꼴 요청 실패 차단, 본문 번호 1~32, 18쪽 별도 마침, 질문 예시, 저장 실패·다중 탭·화면 이탈·응답 유실 후 복구를 포함한다. 타입 검사와 프로덕션 빌드도 통과했다.

첫 5회 반복에서는 기능 단언은 통과했으나 첫 회차의 시험 브라우저 종료 중 남은 지연 로딩 이미지 프록시 요청이 Request context disposed 오류를 냈다. 종료 전 요청 완료 대기를 추가한 뒤 해당 시험을 10회 연속 통과했고, 전체 36개도 다시 통과했다. 이 수정은 검증 스크립트의 종료 처리이며 배포 애플리케이션 코드는 바꾸지 않았다. 실패한 회차를 성공 회차로 집계하지 않았다.

## API·데이터 범위

로컬 서버에는 실제 OpenAI 키를 넣지 않았고 클라우드 연동을 끈 상태로 실행했다. 브라우저는 로컬 HTTP 서버와 합성 주문/그림을 사용했다. 클라우드 시험은 fetch·저장소를 가짜 구현으로 교체하여 외부 유료 API를 호출하지 않았다. 고객의 첨부 PDF·이름·사연을 업로드하거나 수정하지 않았다.

이는 소프트웨어 동작과 출력의 반복 검증이다. 새 AI 작품의 의미적 개연성을 실제 유료 생성으로 5번 평가했다는 뜻은 아니다.

검증 통과 후 GitHub main 반영으로 기존 Netlify 연결의 프로덕션 배포를 시작하고, 공개 release-info.json의 버전과 실제 페이지·글꼴·준비 상태를 별도로 확인한다.

# 낭만한줄 · 현재 개발 상태

아이의 정보와 가족 사연으로 만드는 맞춤형 디지털 동화 플랫폼입니다. 현재 상품 기준은 약 5,000자, 표지 포함 32쪽, 그림 18장입니다. 확정 가격은 5,000원이며 9,900원은 검토안입니다.

## 현재 제공 범위

- 로컬: 질문과 요약, 계좌이체 확인 후 제작 코드 발급, AI 글·삽화 제작, 화풍 열 가지, 읽기·직접 편집·그림 한 장 수정, 책장·백업.
- 공개 배포: 사계의 탑 샘플, 화풍 선택·확대, 실제 제작 예시, 이야기 소재 작성과 브라우저 책장. 온라인 생성·결제는 준비 중으로 안내하고 막습니다. 로컬 파일 주문 저장 방식을 그대로 인터넷에 노출하지 않습니다.
- 직원 사무실과 관리자 API는 .local 페이지 확장자로 구분해 공개 빌드에서 제외합니다. NEXT_PUBLIC_OFFICE_LOCAL=1을 Netlify에 설정하면 안 됩니다.

## 품질 검증

입체 인형·수채화에서 실제 플랫폼 API로 표지·펼침면 각 1장씩 총 4장을 성공적으로 생성하고 시각적으로 확인했습니다. 나머지 8개 화풍과 18장 전체 완주 품질은 미검증입니다. 화풍 참고 이미지·별도 편집한 사계의 탑·실제 API 결과를 구분해 표시합니다. 고객 작품 PDF 자동 제작은 아직 구현하지 않았습니다.

## 실행 및 배포

Node 20 이상에서 npm ci 후 npm run dev. 로컬 사무실 라우트가 필요하면 .env.local에 NEXT_PUBLIC_OFFICE_LOCAL=1을 설정합니다. 비밀 키와 주문 파일은 Git에 저장하지 않습니다.

GitHub main → Netlify 자동 배포 설정을 유지합니다. 공개 주소는 https://nangman-hanjul.netlify.app 입니다. GitHub 저장 성공과 사이트 배포 성공은 별도 확인해야 합니다. 2026-11-07 점검 시 공개 주소는 기존 안내문의 HTTP 503 상태였습니다. Netlify 관리 로그인·배포 제한 해소 후 새 배포를 확인해야 합니다.

## 최신 문서

현재 명세·소개·가격안·실제 API 품질 기록은 docs/current를 확인하세요. 그 밖의 기존 단계별 문서는 과거 기록이며 최신 정책보다 우선하지 않습니다.

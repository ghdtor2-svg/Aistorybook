# 낭만한줄

아이의 정보와 가족 사연을 바탕으로 개인화된 디지털 동화를 만듭니다. 현재 승인된 가격은 5,000원이며, 기본 구성은 약 2,500자·표지 포함 32쪽·그림 18장입니다.

로컬 백오피스에서 입금을 확인하고 키를 발급합니다. 고객은 회원가입 없이 키로 동화를 만들고 다시 엽니다. 10가지 화풍, 읽기·직접 편집·그림 한 장 수정, 브라우저 책장과 백업을 구현했습니다. 고객 작품의 최종 PDF 자동 제작과 자동 이메일 발송은 준비 중입니다.

## 고객 사이트와 관리 연결

관리 화면은 로컬 전용입니다. Netlify production 설정을 완료하면 서명된 관리 연결을 통해 고객 사이트와 비공개 주문·키·결과를 공유하며, 온라인 작업은 Background Functions에서 실행합니다. 조건부 저장으로 중복 작업을 막고 결과 불확실 시 자동 재시도하지 않습니다. 비밀값과 고객 데이터는 저장소에 포함하지 않습니다.

**현재 상태:** 연결 코드와 모의 API 검증을 완료했습니다. 2026-11-07 Netlify 계정에서 운영 크레딧만 남아 production 배포가 중단된 것을 확인했습니다. 실제 온라인 연결은 아직 검증하지 못했으며 로컬 원격 연결도 켜지 않았습니다. 미설정 고객 사이트는 제작 입력을 차단합니다. 설정과 재개 지점은 [연결 상태](docs/current/cloud-connection-status.md)를 참고하세요.

## 실행·검증

Node 22에서 `npm ci`, `npm run build`. `npm run test:cloud`는 모의 저장소와 가짜 AI 응답으로 동시성·인증·작업·복구를 검사하며 유료 API를 호출하지 않습니다. `npm run test:engine`으로 질문 엔진을 확인합니다. 로컬 전용 사무실은 `.env.local`의 `NEXT_PUBLIC_OFFICE_LOCAL=1`로 엽니다. 이 변수는 Netlify에 넣지 마세요.

GitHub main과 기존 Netlify 사이트 nangman-hanjul의 연결은 유지합니다. GitHub 저장 성공과 사이트 배포 성공은 별도 확인합니다. 10가지 참고 그림과 별도 편집한 ‘사계의 탑’은 모든 생성 결과의 품질 보증이 아닙니다. 실제 플랫폼 API 품질 확인은 입체 인형·수채화의 표지와 펼침면 총 4장이며, 18장 전체·다른 8개 화풍은 아직 미검증입니다. 현재 명세와 정책은 docs/current에 있습니다.

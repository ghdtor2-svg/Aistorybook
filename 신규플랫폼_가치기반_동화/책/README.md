# 책 · 「이야기 서랍 — 첫 번째 책」 제작 파일

샘플 동화책과 그 소스. 두 편(「사계의 탑」 · 「23살 우리엄마」)을 한 권으로 묶은 합본이다.
판형 175×225㎜ · **64쪽** · **무선제본** · 흰 본문 용지.

## 산출물

| 파일 | 용도 | 규격 |
|---|---|---|
| `본문_인쇄용.pdf` | **인쇄소 입고용 본문** | 181×231㎜ (재단 후 175×225 · 도련 3㎜ · 재단선 포함) |
| `표지_인쇄용.pdf` | **인쇄소 입고용 표지(별쇄)** | 뒤표지+책등+앞표지 펼침 · 도련 3㎜ · 재단선 포함 |
| `본문_보기용.pdf` | 검토·교정용 | 175×225㎜ (재단 후 크기) |
| `본문_보기용.html` 등 | 빌드 결과 HTML (브라우저로 열면 그대로 보인다) | |

### 인쇄 사양

| 항목 | 값 |
|---|---|
| 판형 | 175 × 225 ㎜ |
| 쪽수 | 64쪽 (8의 배수 — 대수 맞춤) |
| 제본 | 무선제본 |
| 책등 | **4.0㎜** = (64 ÷ 2) × 0.11㎜ + 표지 0.55㎜ |
| 도련 | 3㎜ (사방) |
| 본문 여백 | 안쪽(책등) 28㎜ · 바깥 26㎜ · 위 27㎜ · 아래 27㎜ |
| 색상 | 전 페이지 컬러 · 삽화 래스터 300dpi 이상 |

> 책등 두께는 `build.py` 의 `PAPER_THICK`(본문 용지 1장 두께) · `COVER_THICK` 에서 계산한다.
> 지종을 바꾸면 이 두 값만 고쳐서 다시 빌드하면 표지 책등이 자동으로 맞춰진다.
> 기본값은 본문 모조지 100g/㎡, 표지 스노우지 250g/㎡ 기준.

### 빌드가 자동으로 검사하는 것

| 검사 | 왜 |
|---|---|
| 쪽수가 8의 배수 | 대수 맞춤 — 안 맞으면 제본이 안 된다 |
| 도련 포함 규격 | 재단 여유 |
| **본문이 판면 밖으로 잘리지 않음** | 조판 오류로 글이 잘려 나가는 것을 막는다 |
| **원고 문단 전부 수록** | 원고(`30_content.js`)의 모든 문단이 PDF에 실제로 찍혔는지 대조 |
| 이야기 속표지가 오른쪽 면 | 펼쳤을 때 오른쪽에 와야 한다 |
| 전면 삽화가 속표지와 마주 봄 | 한 펼침으로 읽힌다 |
| 빈 쪽이 연달아 나오지 않음 | 지난 판에서 뒤에 백지 8장이 몰렸던 문제 |
| 본문 중간에 헐렁한 쪽 없음 | 장 끝·삽화 앞은 예외로 둔다 |
| 삽화 300dpi 이상 | 인쇄 품질 |
| 표지 펼침 규격 | 책등 두께 반영 여부 |

### 문단 표기법 (`30_content.js`)

| 접두사 | 뜻 |
|---|---|
| `S\|` | **한 문장 쪽** — 정점에 한 문장만 놓는다 (기획서 §8-7 가드레일 9) |
| `D\|` | 육아일기·사진 뒷면 등 인용 블록 |
| `O\|` | 장면 전환 장식 (✦ ✦ ✦) |
| `B\|아이디` | **밴드 삽화** — 판면 폭 전체. 엔진이 쪽의 위/아래 중 알맞은 자리를 고른다 |
| `P\|아이디\|캡션` | **전면 삽화 쪽** — 한 쪽을 통째로 쓴다 |
| (없음) | 일반 문단. `“` 로 시작하면 대사로 조판된다 |

삽화를 옮기려면 `B|…` / `P|…` 줄을 원하는 문단 **앞**으로 옮기면 된다.
밴드는 본문 사이에 끼어들지 않고 항상 쪽의 위나 아래로 붙는다.

### 화풍 (`20_art_defs.html`)

참고자료(KB 창작동화·동화는 내 친구)의 수채 손그림에 맞춘 구성.

- 색면은 `wc`/`wc2` 필터로 번지게 하고 **가장자리에 물감이 고이는 테두리**를 만든다
- 선은 `pn` 필터로 미세하게 떨리게 해 연필 느낌을 낸다
- 색면이 선 밖으로 살짝 넘치도록 그려 손그림 인상을 만든다
- 인물은 **하나의 캐릭터 시트**(`kidW`/`kidL` + 표정 5종 + 머리 모양 6종)에서 파생한다.
  배색만 CSS 변수(`--hr` 머리 · `--tp` 윗옷 · `--bt` 아래옷 · `--sk` 살색 · `--sf` 신발)로 바꾼다

> `<defs>` 안의 요소는 `<use>` 섀도 트리로 복제되므로 문서 CSS의 **클래스 선택자가 닿지 않는다.**
> 그래서 defs 내부는 전부 인라인 `style` + `var()` 로 칠한다. 새 부품을 추가할 때 주의.

## 원고에 가한 수정

원고는 그대로 두는 것을 원칙으로 했고, 아래만 손봤다. 되돌리려면 `src/30_content.js`에서 해당 문장을 고치면 된다.

**「사계의 탑」**

| 원문 | 수정 | 이유 |
|---|---|---|
| 점점 **장아지기** 시작했어 | 작아지기 | 오타 |
| 그 소리**르** 들으니 | 소리를 | 오타 |
| 방긋방긋 **우는** 아이 | 웃는 아이 | 문맥(환하게 웃고 있었어) |
| 고집은 쉽게 **꺽이지** | 꺾이지 | 맞춤법 |
| 헤메이기 / 헤메고 | 헤매기 / 헤매고 | 맞춤법 |
| **시간의 연못**에 모여 서로의 아름다움을 칭찬해 주던 | **커다란 나무 아래** 모여 | 연못은 3막에서 탑이 멈춘 뒤 처음 드러나는 장소 — 앞에서 모이던 곳으로 쓰면 설정이 어긋난다 |
| "너 혼자서**도 필요해**. 친구는 필요없어" | "너 혼자서도 **충분해**." | 불신이의 논리상 뜻이 통하지 않음 |
| ~할거야 · 오는거지 · 아름다운거야 등 | ~할 거야 · 오는 거지 · 아름다운 거야 | 의존명사 띄어쓰기 |

**「23살 우리엄마」**

| 원문 | 수정 |
|---|---|
| 버스의 번호는**2010**이었다 | 번호는 2010이었다 (띄어쓰기) |
| **2010년4월17일** | 2010년 4월 17일 |
| …. | …… (말줄임표 정리) |

그 밖에 본문 자체는 한 문장도 바꾸지 않았다. 장 제목 8개와 각 장 표제 인용문은 원고 문장에서 그대로 따왔다.
